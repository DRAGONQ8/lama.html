# لَمّة — عالم الألعاب 4.0

مجموعة ألعاب عربية تعمل على الكمبيوتر والهاتف دون اتصال بالإنترنت أو مكتبات خارجية. النسخة الجديدة تحتوي على **28 لعبة**، وواجهة تستفيد من كامل مساحة المتصفح، وزر للشاشة الكاملة، وحفظ محلي للنقاط والإعدادات.

## تشغيل اللعبة

حمّل [lamma_universe.html](./lamma_universe.html)، ثم افتحه في Chrome أو Edge أو Firefox أو Safari. الملف يحتوي على الواجهة والألعاب والمحتوى كله؛ لا يحتاج إلى بقية ملفات المستودع. اضغط زر **⛶ شاشة كاملة** في أعلى الصفحة لتوسيع مساحة اللعب. تتطلب ميزة الشاشة الكاملة ضغطة مباشرة، وقد تختلف إتاحتها على بعض متصفحات الهاتف.

ملف [index.html](./index.html) نسخة مستقلة مطابقة، ويصلح كصفحة البداية عند استضافة المستودع.

## الألعاب

| العالم          | الألعاب                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------- |
| التخمين         | أطلع رقمك، خمن رقمي، شنو في بالك؟، منو أنا؟، فك الشفرة                                              |
| الذكاء          | تحدي الذاكرة، تسلسل الألوان، رتّب الأرقام، سودوكو، حروف مبعثرة، سباق الحساب، لونها شنو؟، كمّل النمط |
| اللمّة          | مثّلها، كلمة السر، منو الجاسوس؟، لا تقولها                                                          |
| المنافسة        | أسرع واحد، إكس أو، وصّل 4                                                                           |
| الألعاب الجديدة | الثعبان، دمج 2048، كاسحة الألغام، المتاهة، كنز المعلومات، اكشف الكلمة، كلمة في ست، صياد الأهداف     |

الألعاب الجماعية تتناوب على الجهاز نفسه. أضف أسماء اللاعبين من زر «اللاعبين»؛ يمكن حفظ حتى 12 لاعبًا. الشاشة الخاصة بالدور تمنع كشف الكلمات أو أدوار الجاسوس لبقية اللاعبين.

## أبرز التحسينات

- تصحيح «يديد/يديدة» إلى «جديد/جديدة»، وتحديث النصوص والعدادات تلقائيًا حسب عدد الألعاب.
- واجهة مرنة للشاشات الكبيرة والصغيرة، بحث ومفضّلة وألعاب حديثة، وأدلة داخل الألعاب.
- مستويات وأحجام وجولات إضافية، وتلميحات وتراجع وملاحظات للسودوكو وتحكم بلوحة المفاتيح واللمس.
- 256 عنصرًا للتخمين، و100 سؤال معرفة، و192 كلمة بتلميحات، وقاموس من 410 كلمات، و83 موقعًا للجاسوس، و130 بطاقة للكلمات الممنوعة.
- إيقاف مؤقت يحفظ وقت الجولة أثناء فتح النوافذ أو مغادرة التبويب.
- تحديات يومية بتوقيت الكويت، وبطولات بأسئلة متساوية للاعبين، وإنجازات وإحصاءات.
- الحفاظ على تقدم الإصدار السابق عند استخدام المتصفح والعنوان نفسيهما، وتصدير واستيراد نسخة JSON احتياطية من الإعدادات.

الحفظ يعتمد على التخزين المحلي في المتصفح. قد يمنع الوضع الخاص أو بعض إعدادات المتصفح الحفظ، وقد يختلف مكان التخزين إذا تغير اسم الملف أو عنوان الصفحة؛ النسخة الاحتياطية تتيح نقل التقدم.

## التطوير

يتطلب التطوير Node.js 22 أو أحدث. لا يحتاج تشغيل ملف HTML إلى Node.js.

```sh
npm ci
npm run build
npm run check
npx playwright install chromium
npm test
```

إذا كان Chromium مثبتًا على النظام، يمكن تشغيل الاختبار عبر:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل ملفات `src/` ثم شغّل `npm run build`. يقوم البناء بفحص صياغة JavaScript وجمع المصدر والأنماط في ملفي HTML مستقلين. لا تعدّل ملفات HTML الناتجة يدويًا.

| الملف                                 | المسؤولية                                        |
| ------------------------------------- | ------------------------------------------------ |
| `src/template.html` و`src/styles.css` | هيكل الصفحة والواجهة العامة                      |
| `src/core.js`                         | الألعاب الأصلية وأدوات الأرقام والذاكرة والجلسات |
| `src/content.js`                      | الكلمات والصفات والتلميحات الإضافية              |
| `src/platform.js`                     | التنقل والإعدادات والحفظ والبطولات والأدلة       |
| `src/advanced.js`                     | ألعاب اللوحات والألغاز والسودوكو والجاسوس        |
| `src/arcade.js` و`src/arcade.css`     | الثعبان و2048 والألغام والمتاهة                  |
| `src/words.js` و`src/words.css`       | المعرفة والكلمات والأهداف                        |
| `src/boot.js`                         | بدء التطبيق                                      |
| `scripts/build.mjs`                   | إنتاج ملف HTML مستقل قابل للحفظ                  |
| `tests/smoke.mjs`                     | اختبارات المتصفح والمنطق والتخطيط والحفظ         |

تشغّل GitHub Actions فحص البناء واختبارات المتصفح عند تحديث المستودع، وتحفظ صورًا لمعاينة الواجهة.
