# لَمّة — عالم الألعاب 5.0

**34 لعبة عربية في ملف HTML واحد** للكمبيوتر والهاتف، تعمل دون اتصال بالإنترنت أو تنزيل مكتبات إضافية. تجمع لَمّة بين الألغاز الفردية والمنافسة مع خصم محلي وألعاب المجموعة، مع حفظ النقاط والإعدادات على المتصفح.

## تشغيل اللعبة

حمّل [lamma_universe.html](./lamma_universe.html)، ثم افتحه مباشرة في Chrome أو Edge أو Firefox أو Safari. هذا هو الملف الوحيد المطلوب للعب؛ يحتوي على الواجهة والألعاب والمحتوى كله. زر **⛶ شاشة كاملة** يوسّع مساحة اللعب، وقد تختلف إتاحته بين متصفحات الهاتف.

ملف [index.html](./index.html) نسخة مستقلة مطابقة، ويصلح كصفحة البداية عند استضافة المستودع.

## اللعب بمفردك ومع المجموعة

أضف أسماء اللاعبين من «اللاعبين»، أو افتح **صالة اللمّة** لاختيار لعبة مناسبة لعددكم. يمكن حفظ 1–12 لاعبًا؛ يحتاج «كأس اللمّة» إلى 4 لاعبين على الأقل، و«الكلمة الدخيلة» و«مجلس الإبداع» إلى 3 لاعبين على الأقل.

**اللعب الجماعي محلي وعلى جهاز واحد بالتناوب.** مرّروا الجهاز بين الأدوار، وشاهدوا البطاقات السرية بعيدًا عن بقية المجموعة. لا توجد غرف لعب عبر الإنترنت أو اتصال بين أجهزة مختلفة.

| العالم   | الألعاب                                                                                                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| التخمين  | أطلع رقمك، خمن رقمي، شنو في بالك؟، منو أنا؟، فك الشفرة، اكشف الكلمة                                                                                                                |
| الذكاء   | تحدي الذاكرة، تسلسل الألوان، رتّب الأرقام، سودوكو، حروف مبعثرة، سباق الحساب، لونها شنو؟، كمّل النمط، كنز المعلومات، كلمة في ست، المتاهة، لوحة المنطق، طفّي الأنوار، مهندس الأنابيب |

## الجديد في 5.0

- **كأس اللمّة:** فريقان وقادة يتناوبون، وجولات تجمع التمثيل والكلمات الممنوعة وأسئلة المعلومات، مع سجل للأدوار ونقاط للفريق وأعضائه.
- **الكلمة الدخيلة:** كلمات متقاربة سرية، وتلميحات ونقاش وتصويت خاص، وإعادة تصويت واحدة عند التعادل.
- **مجلس الإبداع:** مواقف طريفة وردود يكتبها اللاعبون بسرية؛ تظهر الردود دون أسماء قبل التصويت، ثم يُكشف أصحابها بعد اكتماله.
- **لوحة المنطق:** ألغاز Nonogram بأحجام مختلفة، مع فحص الحلول وإضافة خانات معطاة لضمان حل واحد.
- **طفّي الأنوار:** لوحات قابلة للحل وتلميح يحدد ضغطة من أقصر حل للوضع الحالي.
- **مهندس الأنابيب:** شبكات متصلة، وتدوير للقطع وفحص للفتحات؛ يقبل اللعب أي حل يحقق الاتصال دون تسريب.
- **ثلاثة مسارات فردية:** «صفاء الذهن» و«روح المستكشف» و«تحدّي المحترف». كل مسار يجمع ثلاث ألعاب بنتيجة تصل إلى 300 نقطة، ويحفظ أفضل نتيجة والمحطات المكتملة. المحطة التي لم تكتمل تبدأ بجولة جديدة عند استكمال المسار.
- **واجهة اختيار أوسع:** صالة للمجموعة، وفلتر للألعاب الجديدة، وترتيب حسب المقترح أو الاسم أو آخر لعب أو عدد الجولات، مع بحث ومفضّلة ومدة تقريبية لكل لعبة.

تظل المستويات والتلميحات والتراجع وأدلة الألعاب والتحديات اليومية بتوقيت الكويت والبطولات والإنجازات متاحة. يمكن التحكم باللمس أو الفأرة، وتدعم ألعاب الألغاز اختصارات لوحة المفاتيح المناسبة لها.

## الحفظ والاستكمال

تُحفظ النقاط والأسماء والإعدادات والمفضّلة والإضافات محليًا. من الإعدادات تستطيع تصدير نسخة JSON احتياطية واستيرادها لنقل التقدم. يستمر استخدام بيانات الإصدار السابق عند فتح اللعبة في المتصفح والعنوان نفسيهما.

تُحفظ **آخر لوحة غير مكتملة فقط من فك الشفرة أو رتّب الأرقام أو سودوكو** عند اللعب الفردي المستقل دون حد زمني. يظهر زر للاستكمال في الصفحة الرئيسية، ويعيد اللوحة والمحاولات والمساعدات وملاحظات السودوكو ووقت اللعب المسجل. **سجل التراجع يُصفّر عند استعادة اللوحة**. لا تُحفظ الجولات الجماعية السرية أو الجولات اليومية أو جولات البطولة بهذه الطريقة، وللمسارات حفظ منفصل للمحطات المكتملة.

يعتمد الحفظ على سماح المتصفح بالتخزين المحلي. قد يمنع الوضع الخاص أو إعدادات المتصفح الحفظ، وقد يتغير مكان التخزين عند تغيير اسم الملف أو عنوان الصفحة؛ استخدم النسخة الاحتياطية عند نقل اللعبة.

## إصلاحات اللعب والبيانات

جرى توحيد أسماء اللاعبين عند الكتابة والاستيراد وإعادة التحميل، والتحقق من بنية النسخ الاحتياطية، ومنع القيم غير الصالحة من إفساد مجموع النقاط. تُسجّل النتائج مرة واحدة، ويُحتسب حضور الطرفين في ألعاب اللوحات، ويُعامل أصحاب النتيجة المتساوية كمتعادلين. توقّف النوافذ والاستراحة الإدخال والوقت، وتُزال المؤقتات المنتهية بدل تراكمها. وتشمل الإصلاحات كذلك إيقاف الثعبان وحركة المتاهة ومدخلات الكلمات والأهداف أثناء الاستراحة، وحماية انتقال الأدوار السرية.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث. تشغيل ملف HTML نفسه لا يحتاج إلى Node.js.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

إذا كان Chromium مثبتًا على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل ملفات `src/` ثم شغّل `npm run build`. يفحص البناء صياغة JavaScript ويجمع المصدر والأنماط في ملفي HTML مستقلين، ويتحقق `npm run check` من مطابقتهما للمصدر. لا تعدّل ملفات HTML الناتجة يدويًا.
