# لَمّة 7 — كل جولة لها حكاية

**34 لعبة عربية في ملف HTML واحد** للكمبيوتر والهاتف، تعمل دون إنترنت أو تنزيل مكتبات إضافية. الإصدار 7 يضيف التدريب ومعاينة الحركات ومراجعة الإجابات، ويعالج إدخال الجوال وحجب نتائج التخمين بالكيبورد. يحافظ على النقاط والمفضّلة والإعدادات القديمة.

## التشغيل واللعب الجماعي

حمّل [lamma_universe.html](./lamma_universe.html) وافتحه مباشرة في المتصفح. يحتوي الملف على الألعاب والواجهة والمحتوى كله. [index.html](./index.html) نسخة مطابقة تصلح لاستضافة الموقع. زر **⛶ شاشة كاملة** يوسّع مساحة اللعب، بحسب دعم المتصفح.

أضف الأسماء من «اللاعبين»، ثم اختر لعبة أو افتح **صالة اللمّة**. يدعم التطبيق 1–12 لاعبًا؛ يحتاج **كأس اللمّة** إلى 4 لاعبين، و**الكلمة الدخيلة** و**مجلس الإبداع** إلى 3 على الأقل. **الألعاب الجماعية بالتناوب على جهاز واحد**: مرّروا الجهاز وافتحوا البطاقات والتصويت السري بعيدًا عن الآخرين. لا توجد غرف لعب أو اتصال بين أجهزة مختلفة.

| العالم   | الألعاب                                                                                                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| التخمين  | أطلع رقمك، خمن رقمي، شنو في بالك؟، منو أنا؟، فك الشفرة، اكشف الكلمة                                                                                                                |
| الذكاء   | تحدي الذاكرة، تسلسل الألوان، رتّب الأرقام، سودوكو، حروف مبعثرة، سباق الحساب، لونها شنو؟، كمّل النمط، كنز المعلومات، كلمة في ست، المتاهة، لوحة المنطق، طفّي الأنوار، مهندس الأنابيب |
| اللمّة   | مثّلها، كلمة السر، منو الجاسوس؟، لا تقولها، كأس اللمّة، الكلمة الدخيلة، مجلس الإبداع                                                                                               |

## ما تغيّر في 7.0

- **الجوال والتركيز:** نتيجة «أعلى/أقل» فوق حقل التخمين، ونطاق مرئي يتقلص بعد كل محاولة. على الهاتف تبدأ اللعبة بلوحة أرقام داخلية لا تفتح كيبورد الجهاز، مع خيار الكتابة المباشرة وقبول الأرقام العربية والفارسية والسالبة. التخمين غير الصالح لا يستهلك محاولة. الواجهة والنوافذ تتكيّف مع مساحة الكيبورد، وزر **◎** يخفي رأس الموقع ليوسّع مساحة اللعب.
- **معاينة وتدريب الأركيد:** الثعبان يضيف تدريبًا خطوة بخطوة، بمكافأة ثابتة **نقطتين لكل فاكهة، حتى 50 نقطة**، ومراجعة سبب الاصطدام. 2048 يعاين اتجاه الحركة والدمج قبل التنفيذ دون تغيير اللوحة. الألغام تقدم مساعدات منطقية بخصم معلن، تعتمد على الأرقام المكشوفة لا على الألغام المخفية أو افتراض صحة أعلامك. المتاهة تدعم لمس الجار واختيار هدف التلميح وإعادة مشاهدة الرحلة بعد النهاية دون تكرار النقاط.
- **مختبر حركات تفاعلي:** عدسة اختيارية في المنطق والأنوار والأنابيب؛ اللمس يختار خانة للمعاينة، والتنفيذ بزر مستقل. خطة الأنوار تعرض اللوحة المتوقعة فعليًا، وتثبيت الأنابيب يدعم التراجع والإعادة. إصلاح إعادة ضبط الأقفال والخطط وحفظ موضع التمرير في لوحة المنطق.
- **ألغاز بلوحات أوضح:** كتابة رقمية سريعة لفك الشفرة واقتراح احتمال متوافق مع المحاولات، دون قراءة السر أو استهلاك محاولة. الاقتراح يحلل عينة احتمالات ولا يدّعي أنه أفضل تخمين رياضي مطلق. السودوكو يضيف ملاحظات الأرقام الممكنة دون خصم، وأزرارًا مناسبة للجوال. يتحسن تنقل التركيز في اللوحات والذاكرة؛ عُزلت الكسور عن RTL وأُصلح التراجع عندما يبدأ الخصم أولًا.
- **تعلّم على مهلك:** الحساب والألوان والأنماط تبقي شرح الإجابة حتى زر «التالي»، مع توقف المؤقت أثناء القراءة. كنز المعلومات يضيف تدريبًا على الأسئلة الفائتة بلا نقاط إضافية، وأزمنة استجابة ونتائج كل موضوع. اكشف الكلمة يسمح بتخمين الكلمة كاملة؛ الخطأ يكلف خطأين والتكرار لا يخصم مجددًا. كلمة في ست تضيف دفتر أدلة وتراعي الحروف الرمادية والتكرارات في وضع الاستنتاج، وتختصر اللوحة أثناء الكتابة.
- **تفاعل أقوى مع الربع:** شريط مراحل للألعاب الثلاث الجديدة. كأس اللمّة يضيف بطاقة مضاعفة اختيارية مرة للدور، مع سجل ونتائج حسب نوع التحدي؛ عُولج كشف البطاقة المخفية عبر التراجع. الكلمة الدخيلة تضيف دفتر تلميحات علنيًا اختياريًا. مجلس الإبداع يعرض مراجعة خاصة قبل إرسال الرد ويدوّر أول كاتب ومصوّت. أزرار الأدوار القديمة لا تسجل ردًا أو تصويتًا للاعب التالي.
- **صياد الأهداف:** مسار مرتب **1 ثم 2 ثم 3**، وتحكم بأسهم اللوحة، ومراجعة الدقة والاستجابة. تتبدل الأهداف دون إعادة بناء رأس الصفحة.
- **مراجعة واستمرارية:** بعد نتيجة التخمين راجع خطوات تضييق النطاق؛ تعرض النتائج أفضل نقاط اللعبة واقتراح تحدٍّ تالٍ. يُحفظ وضع التركيز ضمن النسخة الاحتياطية الحالية. أُصلح فقدان التركيز بعد إغلاق الدليل وإعادة الرسم، وتزال مؤثرات الاحتفال عند الانتقال إلى لعبة جديدة.

تبقى المسارات الفردية الثلاثة، والتحدّيات اليومية بتوقيت الكويت، والبطولات والإنجازات وأدلة الألعاب متاحة. تدعم الواجهة اللمس والفأرة ولوحة المفاتيح، والمظهرين الفاتح والداكن وتقليل الحركة.

## الحفظ والاستكمال

تُحفظ الأسماء والنقاط والمفضّلة والإعدادات محليًا في المتصفح. **سجل الجولات يعرض آخر 80 نتيجة** مع اسم اللاعب واللعبة والنقاط والوقت؛ يظهر لكل لاعب سجل نتيجته في الألعاب الجماعية. من الإعدادات صدّر نسخة JSON احتياطية أو استوردها لنقل تقدمك. يحتفظ الإصدار بصيغة النسخ الاحتياطية **`lamma-universe`، الإصدار 3**، وتشمل النسخة اختيارات الألعاب والسجل الجديدين.

يُحفظ **آخر لغز فردي مستقل غير مكتمل فقط من فك الشفرة أو رتّب الأرقام أو سودوكو**. الاستكمال يعيد اللوحة والمحاولات والمساعدات وملاحظات السودوكو والوقت المسجل؛ يبدأ سجل التراجع فارغًا بعد الاستعادة. لا يشمل هذا الحفظ الجولات السرية أو اليومية أو جولات البطولة. للمسارات حفظ منفصل للمحطات المكتملة وأفضل نتيجة؛ المحطة غير المكتملة تبدأ من جديد.

يعتمد الحفظ على سماح المتصفح بالتخزين المحلي. قد يمنع الوضع الخاص الحفظ، وقد يختلف مكان التخزين عند تغيير اسم الملف أو عنوان الصفحة؛ استخدم النسخة الاحتياطية عند النقل.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث. تشغيل اللعبة نفسها يحتاج المتصفح فقط.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

إذا كان Chromium مثبتًا على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل `src/` ثم شغّل `npm run build`. يجمع البناء المصدر والأنماط في ملفي HTML مستقلين، ويفحص صياغة JavaScript. `npm run check` يتحقق من مطابقة الملفين للمصدر؛ لا تعدّلهما يدويًا.

اختبارات الإصدار 7 موجودة في `tests/*-v7.mjs`، وتشمل تخمينات الجوال وviewport والتركيز والخصوصية وقواعد المساعدات. `browser-v7` يفحص كل الألعاب على عروض 320 و360 و390 و768 و1440px. يشغّل `scripts/test.mjs` جميع المجموعات ويعيد خطأ إن فشلت أي مجموعة. اختبار مساحة الكيبورد يحاكي تغير viewport؛ لا يحل محل اختبار كيبورد Android/iOS على جهاز فعلي.

تشغّل GitHub Actions فحص البناء واختبارات المتصفح عند تحديث المستودع. اختبارات المتصفح تغطي أيضًا العمل دون الشبكة، وأحجام الشاشات المختلفة، وحماية الإدخال أثناء الاستراحة، وتسجيل النتيجة مرة واحدة. يتطلب مسار إصدار ملف **lamma_universe.html** نجاح الفحوصات قبل رفعه للتنزيل.
