# لَمّة 11 — خيارات أكثر، ولمّة أكبر

**37 لعبة عربية في ملف HTML واحد** تعمل على الهاتف والكمبيوتر دون إنترنت أو حساب. الإصدار 11 يوسّع الجاسوس بكلمات وتصنيفات ودول مشهورة حسب القارات والخليج، ويضيف ثلاث ألعاب وخيارات أوسع لألعاب اللمّة.

## تشغيل النسخة

حمّل [lamma_universe.html](./lamma_universe.html) وافتحه في متصفح حديث. يحتوي الملف على الألعاب والمحتوى والأنماط كلها. [index.html](./index.html) نسخة مطابقة للاستضافة، ومنها GitHub Pages.

## الجاسوس على كيفكم

اختاروا **عام، حيوانات، جماد، أكلات، مهن، رياضات، أماكن أو دول**. في الدول اختاروا الدول المشهورة كلها، أو الخليج، أو قارة مستقلة: أوروبا وآسيا وأفريقيا وأمريكا الشمالية وأمريكا الجنوبية وأوقيانوسيا. تشمل الأسماء فرنسا وألمانيا وإيطاليا وأمريكا وبريطانيا والدول الخليجية الست، مع قوائم مختصرة من الدول المعروفة.

اختاروا جاسوسًا واحدًا، أو جاسوسين عند وجود خمسة لاعبين على الأقل، ووقت النقاش وأسلوب الأسئلة وإظهار قائمة الاحتمالات. الكلمة والأدوار تُعرض لكل لاعب وحده؛ تخفي الاستراحة والانتقال البطاقة السرية. لا تُحفظ أسرار الجولة.

## الألعاب الجديدة والخيارات الموسعة

- **من العلم؟**: أعلام مضمّنة في الملف، مع اختيار الخليج أو القارة وطول الجولة.
- **صح أو خطأ**: حقائق في المعلومات العامة والعلوم والجغرافيا والحيوانات، مع تفسير الإجابة.
- **رتّبها**: رتّب عناصر حسب قاعدة واضحة، وراجع الحل بعد المحاولة.
- **الكلمة الدخيلة**: مجموعات كلمات للحيوانات والجماد والأكلات والدول والخليج.
- **مجلس الإبداع**: اختاروا موضوع المواقف والقصص بدل خلط جميع الموضوعات دائمًا.

## اللعب الفردي

افتح **بمفردك** من شريط التنقل أو **ابدأ جلستك الفردية** من الرئيسية. اختر اللاعب، وإحدى خمس مهارات أو تدريبًا متوازنًا، ومستوى البداية، و3 أو 5 أو 8 جولات. حدد هدفًا يوميًا من 1 إلى 8 جولات، واختر مستوى ثابتًا أو متكيفًا مع نتيجتك. التدريب يسمح لك بمراجعة أدائك دون إضافة نقاط إلى لوحة المنافسة؛ التحدي يسجل نتائج الجولات. نتائج المحطات تُحوّل إلى مقياس 0–100، وتظهر توصيات من آخر نتائجك الشخصية. يمكنك الاستمرار في جلسة محفوظة بعد العودة، بينما تبدأ المحطة غير المكتملة من جديد. يبقى وضع التدريب محفوظًا عند تعديل أسماء اللاعبين أو الرجوع والتقدّم في المتصفح.

تبقى الألعاب المستقلة والاختيار العشوائي وتحديات اليوم والمسارات الثلاثية متاحة. الرجوع إلى قائمة الألعاب يعيد الفلاتر وموضعك السابق، والشعار يعيدك إلى أعلى الرئيسية.

## الإعدادات

من **⚙** خصص المظهر وحجم النص والتباين والحركة والصوت ووضع التركيز. نظّم حفظ اختيارات الألعاب واسترجاع إعداداتها، وأدر المحتوى والنسخ الاحتياطية من أقسام منفصلة. التغييرات تُحفظ محليًا؛ المظهر التلقائي يتبع إعداد الجهاز.

## الحفظ ونقل التقدم

تُحفظ النقاط والمفضلة والإعدادات وسجل آخر 80 نتيجة على هذا المتصفح. صدّر نسخة JSON من الإعدادات قبل نقل الملف أو تغيير عنوان الموقع. يحتفظ الإصدار بصيغة النسخ الاحتياطية **`lamma-universe`، الإصدار 3** ويقرأ بيانات الإصدارات السابقة.

للغز الفردي المستقل غير المكتمل حفظ لوحة واحد من فك الشفرة أو ترتيب الأرقام أو سودوكو؛ يستعيد المحاولات والمساعدات والملاحظات والوقت، ويبدأ سجل التراجع فارغًا. المسارات والجلسات الفردية تحفظ المحطات المكتملة؛ الجولات السرية لا تُحفظ. التخزين المحلي قد يكون غير متاح في الوضع الخاص، ويظهر تنبيه بذلك.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث؛ تشغيل الملف يحتاج المتصفح فقط.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`.

عدّل `src/` ثم شغّل البناء؛ لا تعدّل الملفين المجمّعين مباشرة. يفحص البناء صياغة JavaScript وعدم الحاجة إلى موارد خارجية، ويضمن `check` تطابق المصدر والنسختين.

- `core` و`content` و`platform`: القواعد والمحتوى والحفظ والنسخ الاحتياطية.
- `advanced` و`arcade` و`words` و`party` و`lab`: وحدات الألعاب.
- `collection`: ألعاب الأعلام والحقائق والترتيب ومحتواها المحلي.
- `experience` و`upgrade` و`playflow` و`navigation`: المسارات وتدفق اللعب والتنقل.
- `lobby`: مصدر واحد للصفحة الرئيسية بدل نسخ الواجهة القديمة المكررة.
- `settings`: مركز الإعدادات المنظم وإجراءات استرجاع الإعدادات.
- `solo`: الصالة الفردية والجلسات والإحصاءات الشخصية.
- `boot` و`scripts/build.mjs`: بدء التطبيق وتجميع HTML المستقل.

تفاصيل التغييرات في [ملاحظات الإصدار](./docs/release-notes.md)، ونتائج الفحوص وحدودها في [تقرير التحقق](./docs/verification.md). تشغّل GitHub Actions فحص البناء واختبارات المتصفح عند رفع التغييرات.
