# لَمّة 8 — العب بطريقتك

**34 لعبة عربية في ملف HTML واحد** للكمبيوتر والهاتف، تعمل دون إنترنت أو تنزيل مكتبات إضافية. الإصدار 8 يضيف قواعد وأوضاعًا جديدة للاستنتاج والاستكشاف والمواجهات واللعب الجماعي، ويصلح الحفظ المتزامن وخصوصية الأدوار. يحافظ على النقاط والمفضّلة والإعدادات القديمة.

## التشغيل واللعب الجماعي

حمّل [lamma_universe.html](./lamma_universe.html) وافتحه مباشرة في المتصفح. يحتوي الملف على الألعاب والواجهة والمحتوى كله. [index.html](./index.html) نسخة مطابقة تصلح لاستضافة الموقع. زر **⛶ شاشة كاملة** يوسّع مساحة اللعب، بحسب دعم المتصفح.

أضف الأسماء من «اللاعبين»، ثم اختر لعبة أو افتح **صالة اللمّة**. يدعم التطبيق 1–12 لاعبًا؛ يحتاج **كأس اللمّة** إلى 4 لاعبين، و**الكلمة الدخيلة** و**مجلس الإبداع** إلى 3 على الأقل. **الألعاب الجماعية بالتناوب على جهاز واحد**: مرّروا الجهاز وافتحوا البطاقات والتصويت السري بعيدًا عن الآخرين. لا توجد غرف لعب أو اتصال بين أجهزة مختلفة.

| العالم   | الألعاب                                                                                                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| التخمين  | أطلع رقمك، خمن رقمي، شنو في بالك؟، منو أنا؟، فك الشفرة، اكشف الكلمة                                                                                                                |
| الذكاء   | تحدي الذاكرة، تسلسل الألوان، رتّب الأرقام، سودوكو، حروف مبعثرة، سباق الحساب، لونها شنو؟، كمّل النمط، كنز المعلومات، كلمة في ست، المتاهة، لوحة المنطق، طفّي الأنوار، مهندس الأنابيب |
| اللمّة   | مثّلها، كلمة السر، منو الجاسوس؟، لا تقولها، كأس اللمّة، الكلمة الدخيلة، مجلس الإبداع                                                                                               |
| المنافسة | أسرع واحد، إكس أو، وصّل 4                                                                                                                                                          |
| الأركيد  | الثعبان، دمج 2048، كاسحة الألغام، صياد الأهداف                                                                                                                                     |

## ما تغيّر في 8.0

أوضاع لعب جديدة وأدوات استنتاج لكل الألعاب، مع تطوير للفرد ثم الشخصين والمجموعة:

- معاينة تقسيم نطاق الأرقام، تصحيح أدلة التخمين، أسئلة الصفات، ومطابقة الصورة باسمها.
- ألغاز بدفتر فرضيات، خطط أنوار قابلة للتنفيذ، واختبار ضغط لشبكة الأنابيب.
- تسلسل معكوس، دفع صفوف الأرقام، شرح سودوكو، إدخال حساب مباشر، وقواعد ألوان وأنماط متغيرة.
- تسارع للثعبان، 2048 بحجم 5×5 وتراجع لا يعيد القرعة، علامات شك وتكبير للألغام، ومفاتيح وضوء استكشاف للمتاهة.
- ثقة ومساعدات في المعرفة، مسار إنقاذ للكلمات، تحرير خانات الاستنتاج، وأهداف تختفي بعد حفظ مسارها.
- مواجهات 1/3/5 جولات للشخصين مع تناوب البداية ومراجعة التكتيك.
- مشاهد تمثيل، تخمين مكتوب لكلمة السر، أسئلة الجاسوس، مراقب تابو، استجواب الدخيلة، وتحكيم وتصويت مرتّب للإبداع.
- فلتر للشخصين، مداخل حسب عدد اللاعبين، دليل تحكم لكل لعبة، ومساعدة للحفظ والخصوصية.
- مزامنة نقاط التبويبات المحلية، إصلاح النقاط بلا استجابة صحيحة، وحدود الأسماء البديلة وحماية الأزرار القديمة والبطاقات المخفية.

التفاصيل في [ملاحظات الإصدار](./docs/release-notes.md)، والتحقق وحدوده في [تقرير الاختبارات](./docs/verification.md).

## الحفظ والاستكمال

تُحفظ الأسماء والنقاط والمفضّلة والإعدادات محليًا في المتصفح. **سجل الجولات يعرض آخر 80 نتيجة** مع اسم اللاعب واللعبة والنقاط والوقت؛ يظهر لكل لاعب سجل نتيجته في الألعاب الجماعية. من الإعدادات صدّر نسخة JSON احتياطية أو استوردها لنقل تقدمك. يحتفظ الإصدار بصيغة النسخ الاحتياطية **`lamma-universe`، الإصدار 3**، وتشمل النسخة اختيارات الألعاب وسجل الجولات؛ بيانات مزامنة التبويبات تبقى محلية خارج النسخة الاحتياطية.

يُحفظ **آخر لغز فردي مستقل غير مكتمل فقط من فك الشفرة أو رتّب الأرقام أو سودوكو**. الاستكمال يعيد اللوحة والمحاولات والمساعدات وملاحظات السودوكو والوقت المسجل؛ يبدأ سجل التراجع فارغًا بعد الاستعادة. لا يشمل هذا الحفظ الجولات السرية أو اليومية أو جولات البطولة. للمسارات حفظ منفصل للمحطات المكتملة وأفضل نتيجة؛ المحطة غير المكتملة تبدأ من جديد.

يعتمد الحفظ على سماح المتصفح بالتخزين المحلي. قد يمنع الوضع الخاص الحفظ، وقد يختلف مكان التخزين عند تغيير اسم الملف أو عنوان الصفحة؛ استخدم النسخة الاحتياطية عند النقل.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث. تشغيل اللعبة نفسها يحتاج المتصفح فقط.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

إذا كان Chromium مثبتًا على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل `src/` ثم شغّل `npm run build`. يجمع البناء المصدر والأنماط في ملفي HTML مستقلين، ويفحص صياغة JavaScript. `npm run check` يتحقق من مطابقة الملفين للمصدر؛ لا تعدّلهما يدويًا.

اختبارات الإصدارين 7 و8 موجودة في `tests/*-v7.mjs` و`tests/*-v8.mjs`، وتشمل تخمينات الجوال وviewport والتركيز والخصوصية وقواعد المساعدات. `browser-v7` يفحص كل الألعاب على عروض 320 و360 و390 و768 و1440px. يشغّل `scripts/test.mjs` جميع المجموعات ويعيد خطأ إن فشلت أي مجموعة. اختبار مساحة الكيبورد يحاكي تغير viewport؛ لا يحل محل اختبار كيبورد Android/iOS على جهاز فعلي.

تشغّل GitHub Actions فحص البناء واختبارات المتصفح عند تحديث المستودع. اختبارات المتصفح تغطي أيضًا العمل دون الشبكة، وأحجام الشاشات المختلفة، وحماية الإدخال أثناء الاستراحة، وتسجيل النتيجة مرة واحدة. يتطلب مسار إصدار ملف **lamma_universe.html** نجاح الفحوصات قبل رفعه للتنزيل.
