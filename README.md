# لَمّة 9 — كل جولة لها حكاية

**34 لعبة عربية في ملف HTML واحد** للكمبيوتر والهاتف، تعمل دون إنترنت أو تنزيل مكتبات إضافية. الإصدار 9 يضيف مهمات وقواعد اختيارية للألعاب، ومواجهة ذاكرة للشخصين، واختيارًا عشوائيًا حسب عدد اللاعبين. الرجوع من اللعبة يعيدك إلى مكانك في القائمة مع الفلاتر والتركيز، ويحافظ الإصدار على التقدم والنسخ الاحتياطية القديمة.

## التشغيل واللعب الجماعي

حمّل [lamma_universe.html](./lamma_universe.html) وافتحه مباشرة في المتصفح. يحتوي الملف على الألعاب والواجهة والمحتوى كله. [index.html](./index.html) نسخة مطابقة تصلح لاستضافة الموقع. زر **⛶ شاشة كاملة** يوسّع مساحة اللعب، بحسب دعم المتصفح.

أضف الأسماء من «اللاعبين»، ثم اختر لعبة أو افتح **صالة اللمّة**. يدعم التطبيق 1–12 لاعبًا؛ يحتاج **كأس اللمّة** إلى 4 لاعبين، و**منو الجاسوس؟** و**الكلمة الدخيلة** و**مجلس الإبداع** إلى 3 على الأقل. تحتاج **مثّلها** و**كلمة السر** و**لا تقولها** إلى لاعبين على الأقل. **الألعاب الجماعية بالتناوب على جهاز واحد**: مرّروا الجهاز وافتحوا البطاقات والتصويت السري بعيدًا عن الآخرين. لا توجد غرف لعب أو اتصال بين أجهزة مختلفة.

أزرار **عشوائي بمفردك / لشخصين / للمجموعة** تفتح إعدادات لعبة مناسبة، ولا تبدأ الجولة تلقائيًا. لكل فئة حقيبة مستقلة تتجنب التكرار حتى تنتهي خياراتها المتاحة، ويتطلب الاختيار الجماعي 3 أسماء على الأقل. في بعض ألعاب الشخصين يمكنك تحديد اسمين من قائمة أكبر دون تغيير اللاعبين المحفوظين. العودة تحفظ موضع القائمة داخل جلسة الصفحة؛ الشعار يعيدك إلى أعلاها، وزر المتصفح «إلى الأمام» يفتح إعدادات جديدة بدل إعادة جولة منتهية.

## ما تغيّر في 9.0

تطوير للألعاب الـ34 مع استمرار الأوضاع الكلاسيكية، وإضافة خيارات للفرد ثم الشخصين والمجموعة:

- **التخمين:** صندوق رقم سري، مهمة فتح 3 أقفال بنتيجة واحدة، اختيار أسئلة التحقيق، ودفتر مشتبهين قابل للبحث والاستبعاد اليدوي.
- **الذاكرة والسرعة:** مواجهة ذاكرة يتناوب فيها شخصان؛ الزوج الصحيح يبقي الدور والخطأ ينقله، والمساعدات مغلقة. في السرعة يمكنك اختيار اتجاه السهم بدل الضغط عند أي إشارة.
- **الألغاز واللوحات:** معاينة التهديدات في إكس أو ووصّل 4، وقاعدة خسارة مَن يصنع الخط في إكس أو. استبعاد أرقام الشفرة حسب موضعها، استماع فقط لتسلسل النغمات، تثبيت صفوف اللوحة المنزلقة، وأدلة السودوكو من اللوحة الظاهرة.
- **الحساب والحروف:** البحث عن العدد الناقص، اتباع رموز الألوان، ورقة فروق للأنماط، ومساعدة تثبيت بداية الكلمة بتكلفة معلنة.
- **المعرفة والكلمات:** اختيار حقيقتين من أربع عبارات، ألغاز لعبارات متعددة الكلمات، ومقارنة فرضيتين من أدلة «كلمة في ست». صياد الأهداف يضيف هدفًا يتحرك فعليًا وتصويبًا باللمس أو لوحة المفاتيح.
- **الأركيد:** توصيل طلبات للثعبان، صناديق ثابتة وحد حركات في 2048، جمع آثار والانسحاب في الألغام، والتقاط طرود وإعادتها للقاعدة في المتاهة.
- **مختبر المنطق:** صور متناظرة، مفاتيح أنوار معطلة، وحيّان مستقلان لشبكة الأنابيب. رسم مستمر بالسحب، وتحديد القطعة قبل تدويرها على الهاتف.
- **اللمّة:** حكاية تمثيل من 3 كلمات، تحقيق مكتوب بالتناوب، أدلة وثقة خاصة لتصويت الجاسوس، وحصة تجاوزات اختيارية في تابو. كأس اللمّة يضيف تتابع قائدين؛ الدخيلة تضيف ادعاءً ودفاعًا قبل التصويت، ومجلس الإبداع يضيف قصة مشتركة تكملونها سطرًا بسطر.
- **الموقع والجوال:** اختيار عشوائي مستقل لكل فئة، استعادة مكان الرجوع والفلاتر والتركيز، واجهة أوضح وأزرار وقوائم تتكيف مع الهاتف، مع استمرار وضع التركيز ولوحة الأرقام الداخلية والمظهرين الفاتح والداكن.
- **سلامة الجولات:** إعادة فحص الأسماء والعدد عند البدء، مراجعة فرق الكأس بعد تغيير القائمة، منع الأزرار المخفية والقديمة، والحفاظ على مزامنة النقاط بين التبويبات.

التفاصيل في [ملاحظات الإصدار](./docs/release-notes.md)، والتحقق وحدوده في [تقرير الاختبارات](./docs/verification.md).

## الحفظ والاستكمال

تُحفظ الأسماء والنقاط والمفضّلة والإعدادات محليًا في المتصفح. **سجل الجولات يعرض آخر 80 نتيجة** مع اسم اللاعب واللعبة والنقاط والوقت؛ يظهر لكل لاعب سجل نتيجته في الألعاب الجماعية. من الإعدادات صدّر نسخة JSON احتياطية أو استوردها لنقل تقدمك. يحتفظ الإصدار بصيغة النسخ الاحتياطية **`lamma-universe`، الإصدار 3**، وتشمل النسخة اختيارات الألعاب وسجل الجولات؛ بيانات مزامنة التبويبات تبقى محلية خارج النسخة الاحتياطية.

يُحفظ **آخر لغز فردي مستقل غير مكتمل فقط من فك الشفرة أو رتّب الأرقام أو سودوكو**. الاستكمال يعيد اللوحة والمحاولات والمساعدات وملاحظات السودوكو والوقت المسجل؛ يبدأ سجل التراجع فارغًا بعد الاستعادة. لا يشمل هذا الحفظ الجولات السرية أو اليومية أو جولات البطولة. للمسارات حفظ منفصل للمحطات المكتملة وأفضل نتيجة؛ المحطة غير المكتملة تبدأ من جديد.

يعتمد الحفظ على سماح المتصفح بالتخزين المحلي. قد يمنع الوضع الخاص الحفظ، وقد يختلف مكان التخزين عند تغيير اسم الملف أو عنوان الصفحة؛ استخدم النسخة الاحتياطية عند النقل.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث. تشغيل اللعبة نفسها يحتاج المتصفح فقط.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

إذا كان Chromium مثبتًا على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل `src/` ثم شغّل `npm run build`. يجمع البناء المصدر والأنماط في ملفي HTML مستقلين، ويفحص صياغة JavaScript. `npm run check` يتحقق من مطابقة الملفين للمصدر؛ لا تعدّلهما يدويًا.

اختبارات الإصدارات 7–9 موجودة في `tests/*-v7.mjs` و`tests/*-v8.mjs` و`tests/*-v9.mjs`، وتشمل قواعد الألعاب والتخمينات والجوال والتركيز والخصوصية والحفظ. `navigation-v9` يغطي الرجوع والفلاتر والاختيار العشوائي وتحديد المشاركين، و`browser-v7` يفحص جميع الألعاب على عروض 320 و360 و390 و768 و1440px. يشغّل `scripts/test.mjs` جميع المجموعات ويعيد خطأ إن فشلت أي مجموعة. اختبار مساحة الكيبورد يحاكي تغير viewport؛ لا يحل محل اختبار كيبورد Android/iOS على جهاز فعلي.

تشغّل GitHub Actions فحص البناء واختبارات المتصفح عند تحديث المستودع. اختبارات المتصفح تغطي أيضًا العمل دون الشبكة، وأحجام الشاشات المختلفة، وحماية الإدخال أثناء الاستراحة، وتسجيل النتيجة مرة واحدة. يتطلب مسار إصدار ملف **lamma_universe.html** نجاح الفحوصات قبل رفعه للتنزيل.
