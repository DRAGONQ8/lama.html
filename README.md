# لَمّة 6 — العبها على جوّك

**34 لعبة عربية في ملف HTML واحد** للكمبيوتر والهاتف، تعمل دون إنترنت أو تنزيل مكتبات إضافية. الإصدار 6 يطوّر التحكم وقواعد اللعب والتلميحات والنتائج في الألعاب الموجودة، ويضيف واجهة أسرع لاختيار التحدّي المناسب.

## التشغيل واللعب الجماعي

حمّل [lamma_universe.html](./lamma_universe.html) وافتحه مباشرة في المتصفح. يحتوي الملف على الألعاب والواجهة والمحتوى كله. [index.html](./index.html) نسخة مطابقة تصلح لاستضافة الموقع. زر **⛶ شاشة كاملة** يوسّع مساحة اللعب، بحسب دعم المتصفح.

أضف الأسماء من «اللاعبين»، ثم اختر لعبة أو افتح **صالة اللمّة**. يدعم التطبيق 1–12 لاعبًا؛ يحتاج **كأس اللمّة** إلى 4 لاعبين، و**الكلمة الدخيلة** و**مجلس الإبداع** إلى 3 على الأقل. **الألعاب الجماعية بالتناوب على جهاز واحد**: مرّروا الجهاز وافتحوا البطاقات والتصويت السري بعيدًا عن الآخرين. لا توجد غرف لعب أو اتصال بين أجهزة مختلفة.

| العالم   | الألعاب                                                                                                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| التخمين  | أطلع رقمك، خمن رقمي، شنو في بالك؟، منو أنا؟، فك الشفرة، اكشف الكلمة                                                                                                                |
| الذكاء   | تحدي الذاكرة، تسلسل الألوان، رتّب الأرقام، سودوكو، حروف مبعثرة، سباق الحساب، لونها شنو؟، كمّل النمط، كنز المعلومات، كلمة في ست، المتاهة، لوحة المنطق، طفّي الأنوار، مهندس الأنابيب |
| اللمّة   | مثّلها، كلمة السر، منو الجاسوس؟، لا تقولها، كأس اللمّة، الكلمة الدخيلة، مجلس الإبداع                                                                                               |

## ما تغيّر في 6.0

- **اختيار أسرع:** صفحة رئيسية جديدة، واقتراحات حسب نوع الجلسة، وبحث وترتيب ومفضّلة. تُحفظ إعدادات كل لعبة للجولات المستقلة، ويمكن إعادتها إلى الأصل. إعداداتك الشخصية لا تُستعاد في التحدّيات اليومية أو البطولات أو المسارات.
- **أركيد بتحكم أدق:** الثعبان ينفّذ منعطفين متتاليين بالترتيب، مع سرعة ثابتة أو تصاعدية. في 2048 اختر هدف 1024 أو 2048 أو 4096، وتراجع حتى خمس حركات؛ السحب يظل يعمل بعد تحديث اللوحة. في الألغام الضغط المطوّل يضع علمًا، والضغط على رقم مكشوف يفتح جيرانه بعد اكتمال الأعلام. المتاهة تدعم الحركة حتى التقاطع، وتقيّم كفاءة رحلتك مع جمع النجوم.
- **ألغاز تساعدك على التفكير:** لوحة المنطق توضّح الخطوط المكتملة والمتعارضة، وتشرح الاستنتاجات المضمونة. طفّي الأنوار يعرض أثر الضغطة ويتيح تخطيط مجموعة ضغطات قبل تنفيذها. مهندس الأنابيب يبيّن فتحات التسريب ويتيح تثبيت القطع. الألعاب الثلاث تدعم التراجع والإعادة أثناء اللعب؛ التراجع عن التلميح لا يلغي خصمه.
- **تلميحات أعمق للألعاب الفردية:** إكس أو ووصّل 4 يقدّمان إرشادًا للحركات المهمة، وفك الشفرة يحلّل الاحتمالات والأرقام الممكنة. المستوى السهل في تسلسل الألوان يمنح فرصة ثانية مقابل خصم. تلميح رتّب الأرقام يبحث عن أقصر حل في لوحة 3×3 ضمن حدّ البحث، ويستخدم مسارًا معروفًا للحل إذا لم يصل إليه أو كانت اللوحة أكبر. السودوكو يصحح الإدخالات الخاطئة ويشرح استنتاج الرقم الوحيد قبل اللجوء إلى كشف قيمة من الحل.
- **تعلّم من نتيجتك:** الوقت يتوقف أثناء شرح إجابات الحساب والألوان والأنماط، وتظهر مراجعة الحلول وأزمنة الإجابة. كنز المعلومات يعرض سلسلة النجاح ونتيجة كل موضوع والأسئلة التي فاتتك. اكشف الكلمة يقدّم ثلاثة مستويات تختلف في المحاولات والتلميحات وطول الكلمات، مع حصيلة لكل كلمة. كلمة في ست تدعم الكتابة واللصق من الهاتف، ووضع الاستنتاج الذي يُلزمك بالحروف المكتشفة وأماكنها.
- **كلمات وذاكرة أكثر تفاعلًا:** في حروف مبعثرة يمكنك النقر على الحروف أو الكتابة؛ الحروف المستخدمة تُستهلك من القطع المتاحة. نقاط الذاكرة تراعي حجم اللوحة ودقة المطابقة وسلاسل النجاح، والكشف المؤقت يقلل المكافأة. كلمة السر تتيح تدوين السؤال بجانب الإجابة، مع استعادته عند التراجع.
- **منافسة جماعية أوضح:** كأس اللمّة ينوّع تحدّيات القادة ويبدّل الفريق الذي يبدأ، ويحسب عقوبات التجاوز والمخالفة حتى لو صار رصيد الدور سالبًا. الكلمة الدخيلة تتيح موضوعات للكلمات، وتدوّر بداية التلميحات وتعطي فرصًا إضافية لمن لعب الدور الدخيل أقل. مجلس الإبداع يضيف ردودًا من 40 حرفًا أو سبع كلمات بالضبط، مع تغيير الموقف قبل الكتابة. زر الإخفاء وEscape يحميان الشاشات الخاصة ويحفظان مسودة الرد؛ النتائج لا تُحسب قبل اكتمال التصويت.
- **تحدّي سرعة وتركيز:** صياد الأهداف يعرض عمر الهدف وزمن الاستجابة، ويقبل الأرقام 1–9 للشبكة الصغيرة. وضع التركيز يضيف قنبلة يجب تجنبها. الضغطات المكررة لا تضاعف إصابة الهدف أو تسجيل بطاقة الفريق.

تبقى المسارات الفردية الثلاثة، والتحدّيات اليومية بتوقيت الكويت، والبطولات والإنجازات وأدلة الألعاب متاحة. تدعم الواجهة اللمس والفأرة ولوحة المفاتيح، والمظهرين الفاتح والداكن وتقليل الحركة.

## الحفظ والاستكمال

تُحفظ الأسماء والنقاط والمفضّلة والإعدادات محليًا في المتصفح. **سجل الجولات يعرض آخر 80 نتيجة** مع اسم اللاعب واللعبة والنقاط والوقت؛ يظهر لكل لاعب سجل نتيجته في الألعاب الجماعية. من الإعدادات صدّر نسخة JSON احتياطية أو استوردها لنقل تقدمك. يحتفظ الإصدار بصيغة النسخ الاحتياطية **`lamma-universe`، الإصدار 3**، وتشمل النسخة اختيارات الألعاب والسجل الجديدين.

يُحفظ **آخر لغز فردي مستقل غير مكتمل فقط من فك الشفرة أو رتّب الأرقام أو سودوكو**. الاستكمال يعيد اللوحة والمحاولات والمساعدات وملاحظات السودوكو والوقت المسجل؛ يبدأ سجل التراجع فارغًا بعد الاستعادة. لا يشمل هذا الحفظ الجولات السرية أو اليومية أو جولات البطولة. للمسارات حفظ منفصل للمحطات المكتملة وأفضل نتيجة؛ المحطة غير المكتملة تبدأ من جديد.

يعتمد الحفظ على سماح المتصفح بالتخزين المحلي. قد يمنع الوضع الخاص الحفظ، وقد يختلف مكان التخزين عند تغيير اسم الملف أو عنوان الصفحة؛ استخدم النسخة الاحتياطية عند النقل.

## التطوير والتحقق

يتطلب التطوير Node.js 22 أو أحدث. تشغيل اللعبة نفسها يحتاج المتصفح فقط.

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

إذا كان Chromium مثبتًا على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

عدّل `src/` ثم شغّل `npm run build`. يجمع البناء المصدر والأنماط في ملفي HTML مستقلين، ويفحص صياغة JavaScript. `npm run check` يتحقق من مطابقة الملفين للمصدر؛ لا تعدّلهما يدويًا.
