# Logic laboratory V14

Scope: all three games in `src/lab.js`. Existing generators, storage keys, daily/tournament seeds and scoring rules are retained.

| Game                  | Change                                                                                                                                                                                                                                                                     | Browser coverage                                                                                                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Nonogram (`nonogram`) | Optional line map shows completed, contradictory and possible rows/columns; selecting a line focuses its first unknown cell and opens the correct notebook axis. It uses visible clues and marks only.                                                                     | Map navigation, contradiction recovery, focus, unchanged board/moves/hints; complete generated puzzles at all three difficulties in classic and mirror rules.                        |
| Lights Out (`lights`) | Separate undo/redo for planning drafts, including clearing and row chasing. Hints now suggest a legal edit to the projected draft while preserving the plan; an already solved plan receives no hint penalty. Executing a move clears obsolete draft history.              | Draft branching, clear/chase reversal, step execution, duplicate hint charging, preserved draft, legal switches; complete every difficulty in classic and disabled-switch rules.     |
| Pipes (`pipes`)       | Optional orientation comparison shows all distinct rotations with whole-network leak/connectivity counts. Applying a rotation counts the shortest number of quarter-turns and creates one reversible history entry. Opening the comparison makes board taps select pieces. | Read-only comparison, shortest rotation, undo/redo, obsolete signatures, detached controls, locks and flow-test guards; complete every difficulty in classic and two-district rules. |

Bug fix: locking a pipe while flow simulation was open previously called `labRemember()` and silently deleted the simulation. Locking is now guarded and disabled during flow testing, consistent with rotation and hint controls.

Run `CHROMIUM_PATH=/usr/bin/chromium node tests/lab-v14.mjs`. The suite contains **11 browser checks**, including **18 complete generated puzzles** (3 games × 3 difficulties × 2 rules), at a 390×844 viewport. Each check rejects uncaught browser exceptions. Getter traps verify the new Nonogram and Pipes analysis does not read generated answers. It is regression coverage, not exhaustive proof for every possible random puzzle or browser/device.

The eleventh check opens all three new tools in both mobile themes and runs every default Axe rule, without disabled rules. It saves the six audits and summary under `test-results/lab-v14/`. This catches the orientation cards’ former accessible-name mismatch: their names now use the visible action/stat text, with direction details provided separately as an accessible description.
