# التحقق من لَمّة 10

## نطاق الفحص

يشغّل المشروع **33 مجموعة متصفح**: 29 مجموعة للألعاب والحفظ والملاحة من الإصدارات السابقة، وأربع مجموعات جديدة للإعدادات والجلسات الفردية وإصلاحات اللعب.

- فحص تشغيل الألعاب الـ34 وقواعدها والخصم والتلميحات وتسجيل النتائج مرة واحدة.
- فحص واجهة شامل لـ **809 شاشات** على عروض 320 و360 و390 و768 و1440px؛ لم تسجل الجولة المحلية أخطاء تخطيط أو JavaScript أو طلبات موارد خارجية.
- الإعدادات: ترحيل النسخ الاحتياطية v3، ورفض القيم غير الصالحة قبل الاستبدال، وتبويبات بلوحة المفاتيح، ومظهر حسب الجهاز وحجم النص والتباين، وقياس مستوى الصوت الفعلي.
- فحص جميع شاشات إعداد الألعاب والهاتف بعرض 320px مع نص 130% وتباين أقوى؛ تكبير القراءة يحافظ على أبعاد لوحة الذاكرة.
- تعطيل حفظ الاختيارات واستعادتها، وإعادة لعبة واحدة أو جميع الألعاب، وتنظيف بيانات محددة دون فقد النقاط، ومنع تأكيد قديم، والمحافظة على الجولة الحية والتوقف والتركيز.
- الصالة الفردية: جلسة تدريب كاملة وجلسة نقاط، تغير الصعوبة والاستكمال وإعادة التحميل والرجوع، وفصل التدريب عن النقاط والإنجازات، والحفاظ على إعدادات الألعاب المستقلة.
- تحقق دمج السجلات الفردية بعد الكتابات المتعارضة ومنع تكرار محطة محفوظة في تبويبين، مع سجل محدود وتقدم تراكمي.
- إصلاحات قابلة لإعادة إنتاجها: تناقضات السودوكو، قبول جذري التربيع، الكتابة داخل المحررات وتركيب الأحرف، أزرار المختبر القديمة، وتركيز إجابات المعرفة.
- الاختبارات السابقة تشمل أيضًا الحفظ والمزامنة والبطولات والخصوصية والتحكم والإيقاف والهواتف والعمل دون الشبكة. لم تُحذف الاختبارات القديمة أو يُضعف أي فحص.

## نتيجة التحقق المحلي

نجح بناء النسخة المستقلة وفحص مطابقة المصدر والملفين. الملفان `index.html` و`lamma_universe.html` متطابقان ويحتويان الموارد كلها؛ الحجم نحو **1.3MB**.

مجموعات الانحدار السابقة: **28 من 29 ناجحة**. المجموعة المتبقية `reliability` اجتازت 19 حالة وتعذر فحص فتح `file:///` لأن Chromium في بيئة التطوير يرفضه قبل تحميل التطبيق بـ **`ERR_BLOCKED_BY_ADMINISTRATOR`**. هذا القيد موجود على الملف الأصلي أيضًا؛ لم يُتجاوز الفحص. نجحت فحوص العمل دون الشبكة عبر HTTP.

اجتازت المجموعات الجديدة الأربع **35 حالة** على ملف HTML النهائي: 10 للإعدادات، و15 للجلسات الفردية، و5 لإصلاحات القواعد والإدخال، و5 لإصلاحات المختبر والمعرفة. لذلك اجتازت النسخة محليًا **32 من 33 مجموعة**؛ تعود المجموعة المتبقية إلى قيد فتح الملف المذكور أعلاه.

نجح أيضًا فحص التنسيق وفحص الفروقات. تحفظ السجلات والصور المحلية داخل `test-results/` ولا تدخل ملفات المصدر.

## نسخة GitHub والتنزيل

تشغّل [GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions) المجموعات الـ33 على النسخة المرفوعة. مسار **Downloadable HTML release** يفحص البناء وكل المجموعات، بما فيها فتح HTML المحلي دون إنترنت، قبل نشر مرفق الملف. راجع [إصدار v10.0.0](https://github.com/DRAGONQ8/lama.html/releases/tag/v10.0.0) لتفاصيل ملف التنزيل.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`.

## الحدود العملية

الجماعي بالتناوب على جهاز واحد. محاكاة حجم الشاشة ولوحة المفاتيح لا تعادل تجربة كل هاتف فعلي. النقاط تختلف باختلاف إعدادات الألعاب؛ نتائج محطات النادي الفردي تحول إلى مقياس 0–100 لتلائم ملخص الجلسة. تُحفظ المحطات المكتملة، بينما تبدأ محطة النادي غير المكتملة من جديد. استكمال لوحة مستقلة متاح للشفرة وترتيب الأرقام والسودوكو فقط.

يتطلب الحفظ سماح المتصفح بالتخزين المحلي. انتقال الملف أو العنوان قد يغير مكان التخزين؛ صدّر نسخة احتياطية قبل النقل. لا تُحفظ الكلمات والأدوار الجماعية السرية.
