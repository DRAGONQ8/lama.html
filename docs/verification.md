# التحقق من لَمّة 7

## ما اختُبر

- تشغيل الألعاب الـ34 في Chromium، ومراجعة الواجهة والصور، على عروض 320 و360 و390 و768 و1440px.
- فحص متصفح موسع: 809 حالات، تشمل الإعدادات واللعب والأدلة والنتائج، والفلاتر والبحث والمفضّلة، والقائمة الموسعة، والبطولات، والمظهر الفاتح، و12 لاعبًا، ومراجعات الجولات.
- الخصوصية عند تمرير الجهاز والإيقاف، منع الأزرار القديمة والتسجيل المكرر، الحفظ والاستيراد والاستكمال، والعمل دون الشبكة.
- استنتاج مساعد الألغام عبر 120 حقلًا مولدًا، ومعاينات الأركيد والمنطق دون تغيير الحالة قبل التنفيذ.
- التخمين بلوحة أرقام الهاتف، الأرقام العربية والفارسية، الأرقام السالبة ونطاقات 60 خانة، مدخلات غير صالحة دون خصم، والتحكم والتركيز بلوحة المفاتيح.
- تغير مساحة viewport عند الكتابة، ظهور أعلى/أقل فوق الإدخال، النوافذ القصيرة، واختلاف تصغير نافذة الكمبيوتر عن فتح الكيبورد.

## النتائج المحلية

`npm run build` و`npm run check` و`git diff --check` وفحص Prettier ناجحة. الملفان `index.html` و`lamma_universe.html` متطابقان مع المصدر، وحجمهما قرابة 805KB لكل ملف، دون موارد خارجية.

اجتازت 14 من 15 مجموعة اختبار متصفح التشغيل الكامل محليًا. المجموعة المتبقية هي reliability: نجح 19 فحصًا فيها، وتعذر فحص فتح الملف مباشرة لأن Chromium في بيئة العمل يرفض `file:///` بـ `ERR_BLOCKED_BY_ADMINISTRATOR`. ظهر القيد نفسه على الإصدار السابق قبل التعديلات. بقي اختبار الملف مفعّلًا في GitHub Actions، ويفشل أمر `npm test` إذا فشل؛ لم يُخفَ أو يُتجاوز.

اجتازت إعادة التحقق النهائية للكيبورد والتركيز 9/9، والفحص الموسع 809/809 شاشة بدون أخطاء JavaScript أو طلبات خارجية أو عيوب تخطيط مثبتة. الصور وتقارير القياس تحفظ في `test-results/` وتُرفع كأثر من GitHub Actions؛ لا تدخل ملفات نتائج الاختبارات في المصدر.

## حدود الفحص

المستودع ليس موقعًا حيًا: GitHub Pages غير مفعّل له وقت الفحص. شُغلت النسخة محليًا عبر HTTP في المتصفح. محاكاة viewport واستخدام لوحة أرقام داخلية لا يثبتان سلوك كل كيبورد Android/iOS؛ يلزم جهاز فعلي للتحقق من فروق نظام التشغيل. الاختبارات تغطي المسارات الأساسية والانحدارات المذكورة، وليست حصرًا لكل تسلسل ضغط ممكن.
