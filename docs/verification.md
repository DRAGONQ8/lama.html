# التحقق من لَمّة 12

## نطاق الفحص

يشغّل `npm test` **43 مجموعة اختبار متصفح**: المجموعات الـ36 السابقة وسبع مجموعات جديدة للإصدار 12. تستخدم عملية التشغيل الملف المستقل المبني نفسه، ويتيح كل اختبار جديد بناء المصادر عند تشغيله مباشرة.

- تشغيل الألعاب الـ37 من أزرار البداية، والعمل دون الشبكة وعدم طلب موارد خارجية.
- الجاسوس: الأدوار، والبداية العشوائية أو الاتفاق خارج الموقع، واختيار السائل والمجيب والسؤال بحرية، ثم التصويت والكشف والتخمين بهذا الترتيب.
- بقاء الكلمة مخفية عند كشف الجاسوس، والتصويت لجاسوس أو جاسوسين وحدود التعادل، وجميع نتائج مرحلتي النقاط، ومنع تكرار النتيجة وأزرار لاعب أو جولة قديمة.
- البحث والاختيار دون اعتماد تلقائي، والأسماء البديلة واختلافات الكتابة العربية، وحفظ مسودة التخمين وإخفاؤها عند الاستراحة، وقوائم الاحتمالات الاختيارية.
- بحث الكلمات والاحتمالات، ومسودات الكتابة، وخصوصية التمثيل، وثلاثة أقفال مختلفة، والذاكرة ونتائج سرعة الاستجابة.
- تجربة نقلتين في ألعاب اللوحات، وتلميحات الشفرة، والتسلسل والحساب والألوان والأنماط والسودوكو، والتراجع عن كتابة الحروف، وحماية بطاقات تابو.
- تحكم الثعبان و2048، وفحص الألغام قبل كشفها، وتكبير المتاهة والتحرك داخلها، ودفاتر الكلمات ومراجعات ألغاز المنطق.
- توزيع الفرق يدويًا، والأسئلة الحرة في الدخيلة، وشروط الكتابة الإبداعية، ومراجعة الإجابات الفائتة دون نقاط إضافية، وإعادة ألعاب المعرفة بنفس الاختيارات.
- دليل تحكم للألعاب كلها، وF1 للمساعدة، وإخفاء البطاقات وتوقيف الوقت عند تجميد صفحة الجوال.
- مراجعة الواجهات على عروض 320 و360 و390 و768 و1440px، والنص الكبير والتنقل ولوحة المفاتيح. يشمل التدقيق العام 869 شاشة.
- تبقى فحوص الحفظ والمزامنة والبطولات والمسارات والجلسات الفردية والنسخ الاحتياطية ضمن المجموعات السابقة.

## نتائج الفحص المحلي

نجحت **58 حالة جديدة** في سبع مجموعات: 11 للجاسوس، و10 للألعاب الأساسية، و10 للألعاب المتقدمة، و6 للأركيد، و9 للكلمات والمنطق، و9 للّمة وألعاب المعرفة، و3 للنظام العام. نجح تدقيق 869 شاشة بخمسة عروض دون ملاحظات تخطيط أو أخطاء JavaScript أو طلبات خارجية، وفُحصت المتاهة أيضًا في الوضع الأفقي القصير. نجح بناء الملف المستقل وفحص مطابقته للمصدر. الملفان `index.html` و`lamma_universe.html` متطابقان، بحجم نحو **1.4MB** ودون موارد خارجية.

متصفح Chromium في بيئة التطوير يحجب التنقل إلى ملفات `file:///` بسياسة `ERR_BLOCKED_BY_ADMINISTRATOR`؛ لذلك لا يمكن محليًا إكمال حالة فتح الملف المنزّل بهذه الطريقة. تبقى الحالة مفعلة في الاختبارات وتعمل على GitHub Actions. اختبارات التشغيل دون شبكة عبر HTTP مستقلة عنها.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`.

لا يُتجاوز فحص التنزيل: يشغّل مسار **Downloadable HTML release** في GitHub Actions المجموعات الـ43، ولا ينشر المرفق إلا بعد نجاحها. بعد دمج التحديث يمكن تشغيله بالوسم `v12.0.0` لإصدار الملف المستقل.

## الحدود العملية

الجماعي بالتناوب على جهاز واحد. محاكاة أحجام الشاشة لا تعادل تجربة كل هاتف فعلي. لا تُحفظ الكلمات والأدوار الجماعية السرية. قوائم الدول مختارة من دول معروفة وليست أطلسًا شاملًا؛ أوقيانوسيا تضم أستراليا ونيوزيلندا فقط.

الحفظ مرتبط بالمتصفح وعنوان الملف، وقد لا يتاح في الوضع الخاص. صدّر نسخة احتياطية من الإعدادات عند نقل اللعبة إلى جهاز أو عنوان آخر. الجلسات الفردية المتكيفة تستخدم ألعابها التدريبية الحالية؛ بقية الألعاب متاحة من الفهرس والاختيار الفردي العشوائي.
