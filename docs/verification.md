# التحقق من لَمّة 13

تاريخ المراجعة: 17 أكتوبر 2026. يشرح [تقرير المراجعة](./audit-v13.md) ما فُحص قبل بدء التعديل، و[ملاحظات الإصدار](./release-notes.md) التغييرات النهائية.

## نطاق التحقق

يشغّل `npm test` **51 مجموعة اختبار متصفح**: المجموعات الـ43 السابقة وثماني مجموعات جديدة. يستخدم المشغّل ملف HTML المستقل المبني؛ وتتيح اختبارات الوحدات الجديدة تجميع المصدر عند تشغيلها منفردة.

- تشغيل الألعاب الـ37 والتحقق من النقاط والمساعدات والتوقف والحماية من أزرار الجولات القديمة.
- اختبار الحفظ والاستكمال والنسخ الاحتياطية والمزامنة بين التبويبات والجلسات الفردية والمسارات والبطولات.
- **49 حالة جديدة** للتحكم والتدريب والخصوصية والتنزيل، مع اختبار ضغطات فعلية بالفأرة واللمس وEnter لتأكيد التخمين.
- تدقيق تخطيط **869 شاشة** بعروض 320 و360 و390 و768 و1440px، بما فيها الإعدادات والنتائج والنوافذ والنص المكبّر.
- تدقيق axe لقواعد WCAG A/AA دون تعطيل قواعد: **172 شاشة** تشمل إعدادات وبداية كل لعبة والشاشات المشتركة، بالمظهرين الداكن والفاتح.
- تنزيل HTML من الإعدادات بعد عرض أسماء ومحتوى خاص، ثم التأكد من غيابها عن الملف وتشغيل ألعاب الملف المنزّل الـ37 مع تعطيل الشبكة.
- تحقق مساعد الألغام باستخدام حراس يمنعون قراءة الخانات المخفية، واستنتاج متسلسل، و120 حقلًا مولدًا. أُجري أيضًا فحص مستقل لجميع **19683 حالة حقل 3×3**، وأنتج 15139 برهانًا دون استنتاج خاطئ أو قراءة مخفية.

## النتائج

نجحت **50 من 51 مجموعة محليًا** بعد إعادة فحص التصحيحات. تعذّر فحص الفتح المباشر للملف بسبب سياسة المتصفح المبينة أدناه؛ بقي الاختبار مفعّلًا للتحقق منه على GitHub قبل اعتماد التحديث.

نجح تدقيق التخطيط المحلي للـ869 شاشة دون ملاحظات، واجتازت الشاشات الـ172 فحوص axe دون مخالفات أو أخطاء JavaScript أو طلبات خارجية. نجحت كذلك فحوص الصياغة والتنسيق وتطابق البناء. الملفان `index.html` و`lamma_universe.html` مستقلان ومتطابقان، بحجم نحو **1.4MiB** ودون موارد خارجية.

متصفح بيئة التطوير يحجب التنقل إلى `file:///` بسياسة `ERR_BLOCKED_BY_ADMINISTRATOR`. يبقى اختبار الفتح المباشر مفعّلًا ويُشغّل في GitHub Actions؛ لا يُحوّل إلى نجاح صوري أو حالة متجاوزة. اختبار بايتات الملف المنزّل وتشغيلها دون شبكة منفصل عنه.

تتوفر نتائج الخادم وتقارير المتصفح في [GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions/workflows/test.yml)، ويضم مرفق `browser-previews` تقرير `accessibility-v13.json` وتقارير التخطيط والصور. يُتحقق من الفرع المرشح قبل اعتماد التحديث في الفرع الرئيسي.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع متصفح النظام المثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`. دون هذا المتغير تستخدم الاختبارات متصفح Playwright المضمّن، بما فيه GitHub Actions. يرفض البناء فقد ملف أنماط أو تلف موضع الدمج أو إغلاق وسوم JavaScript/CSS المضمّنة.

## الحدود العملية

الفحوص الآلية على Chromium ومحاكاة أحجام الهاتف؛ لا تعادل تجربة كل هاتف فعلي أو تحققًا يدويًا شاملًا بكل متصفح وتقنية مساعدة. نتيجة axe تعني اجتياز القواعد الآلية المشغّلة في الشاشات المحددة، وليست شهادة إتاحة كاملة.

اللعب الجماعي بالتناوب على جهاز واحد. لا يحفظ تنزيل HTML أسرار الجولة أو الأسماء أو التقدم؛ نقل البيانات يستعمل نسخة JSON منفصلة بصيغة الإصدار 3. الحفظ مرتبط بالمتصفح والعنوان، وقد لا يتاح في الوضع الخاص. لا تُحفظ الجولات الجماعية السرية، ويقتصر استكمال الألغاز المستقلة على فك الشفرة وترتيب الأرقام وسودوكو.
