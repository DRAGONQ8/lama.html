# التحقق من لَمّة 11

## نطاق الفحص

يشغّل المشروع **36 مجموعة اختبار متصفح**: 33 مجموعة سابقة وثلاث مجموعات للجاسوس وتصنيفات ألعاب اللمّة والألعاب الجديدة.

- تشغيل الألعاب الـ37 من أزرار البداية، والعمل دون الشبكة وعدم طلب موارد خارجية.
- الجاسوس: عام والحيوانات والجماد والدول والخليج وكل قارة، وحفظ المرشح، والتخمين والتصويت لجاسوس أو جاسوسين، وإخفاء الأدوار والاحتمالات عند اختيار ذلك.
- الكلمة الدخيلة: حصر الكلمات في التصنيف المختار وعدم تكرار الأزواج في العام. مجلس الإبداع: موضوع الردود والقصص، وحفظه عند إعادة المباراة.
- من العلم؟ وصح أو خطأ ورتّبها: كل طرق اللعب، الإجابات الخاطئة والصحيحة، المراجعة، وعدم تكرار النقاط أو قبول أزرار من جولة قديمة.
- مراجعة الواجهات على عروض 320 و360 و390 و768 و1440px، والنص الكبير والتنقل ولوحة المفاتيح.
- تشمل فحوص الإصدارات السابقة الحفظ والمزامنة والبطولات والمسارات والجلسات الفردية والنسخ الاحتياطية والخصوصية.

## نتيجة التحقق المحلي

نجح بناء الملف المستقل وفحص مطابقته للمصدر. الملفان `index.html` و`lamma_universe.html` متطابقان، بحجم نحو **1.3MB** ودون موارد خارجية.

نجحت **22 حالة جديدة**: 10 للجاسوس، و4 لتصنيفات ألعاب اللمّة، و8 للأعلام والحقائق والترتيب. شمل فحص الواجهات **869 شاشة** بخمسة عروض، دون ملاحظات تخطيط أو JavaScript أو طلبات موارد خارجية. نجح فحص التنسيق والفروقات.

متصفح Chromium في بيئة التطوير يحجب التنقل إلى ملفات `file:///` بسياسة `ERR_BLOCKED_BY_ADMINISTRATOR`، ولذلك يتعذر محليًا فحص الملف المنزّل بهذه الطريقة. نجحت فحوص العمل دون الشبكة عبر HTTP. لا يُتجاوز فحص الملف: مسار **Downloadable HTML release** في [GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions) يشغّل المجموعات الـ36، بما فيها فتح HTML المحلي دون شبكة، ولا ينشر المرفق إلا بعد نجاحها كلها.

## نسخة GitHub والتنزيل

[الإصدار v11.0.0](https://github.com/DRAGONQ8/lama.html/releases/tag/v11.0.0) يرفق ملف HTML المستقل الناتج من المصدر نفسه الذي يفحصه مسار الإصدار. يمكن مراجعة نتيجة كل مجموعة من سجل GitHub Actions.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`.

## الحدود العملية

الجماعي بالتناوب على جهاز واحد. محاكاة أحجام الشاشة لا تعادل تجربة كل هاتف فعلي. لا تُحفظ الكلمات والأدوار الجماعية السرية. قوائم الدول مختارة من دول معروفة وليست أطلسًا شاملًا؛ لذلك أوقيانوسيا تضم أستراليا ونيوزيلندا فقط.

الحفظ مرتبط بمتصفحك وعنوان الملف، وقد لا يتاح في الوضع الخاص. صدّر نسخة احتياطية من الإعدادات عند نقل اللعبة إلى جهاز أو عنوان آخر. الجلسات الفردية المتكيفة تستخدم ألعابها التدريبية الحالية؛ الألعاب الجديدة متاحة من الفهرس والاختيار الفردي العشوائي.
