# التحقق من لَمّة 14

تاريخ المراجعة: 18 أكتوبر 2026. يشرح [تقرير الألعاب الـ37](./audit-v14.md) تغييرات كل لعبة، وتوثّق ملفات الوحدات حالات اللعب الفعلية وحدودها.

## نطاق الفحص

يشغّل `npm test` **58 مجموعة اختبار متصفح**: المجموعات الـ51 السابقة وسبع مجموعات جديدة تضم **68 حالة**. تختبر المجموعات النسخة المجمّعة أو المصدر المطابق لها؛ يؤكد `npm run check` تطابق ملفَي HTML مع المصدر.

| المجموعة الجديدة     | الحالات | النطاق                                                                   |
| -------------------- | ------- | ------------------------------------------------------------------------ |
| core-v14             | 9       | ثماني ألعاب تخمين وذاكرة وجماعة، مع 320px ودون شبكة                      |
| advanced-v14         | 14      | اثنتا عشرة لعبة لوحات وتحديات، توليد قابل للإعادة، و320px                |
| arcade-v14           | 13      | أربع ألعاب، الفوز والخسارة والمهمات والتراجع واللمس                      |
| words-collection-v14 | 9       | سبع ألعاب كلمات ومعرفة، و14 فحص مظهر/جوال/إتاحة                          |
| party-v14            | 5       | جلسات مكتملة للكأس والدخيلة والإبداع، النقاط والخصوصية                   |
| lab-v14              | 10      | ثلاث ألعاب و18 لغزاً مكتملًا عبر جميع المستويات والقواعد                 |
| platform-v14         | 8       | البحث والفلاتر والمفضلة والرجوع والمظهر واتجاه العدادات في الألعاب الـ37 |

تشمل الفحوص السابقة الحفظ والاستكمال والنسخ الاحتياطية والمزامنة بين التبويبات والجلسات الفردية والبطولات والمسارات، والتوقف والمساعدات والتحكم والنقاط. يبقى تدقيق التخطيط الشامل بعروض **320 و360 و390 و768 و1440px**، وفحص axe لـ**172 شاشة** بالمظهرين دون تعطيل قواعد WCAG A/AA.

تنزّل فحوص الأوفلاين بايتات HTML من الإعدادات بعد عرض أسماء ومحتوى خاص، وتتحقق من غيابها عن الملف ثم تشغّل الألعاب الـ37 مع تعطيل الشبكة. تُفحص أدوات الألغام والأنابيب ولوحة المنطق بحراس يمنعون قراءة الإجابات المخفية حيث يلزم الاستنتاج من المعلومات العامة.

## النتائج والتقارير

تتوفر نتائج التحقق النهائية لكل نسخة في [GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions/workflows/test.yml). يتضمن مرفق `browser-previews` سجلات المجموعات الـ58 داخل `test-results/suites/`، وتقرير التخطيط `browser-v7/report.json` وتقرير الإتاحة `accessibility-v13.json`، وصور الإصدار الجديد داخل مجلدات `*-v14/`. يُفحص الفرع المرشح قبل اعتماد تحديثه على `main`.

الملفان `index.html` و`lamma_universe.html` مستقلان ومتطابقان، بحجم نحو **1.44MiB** ودون موارد خارجية. فحوص الصياغة والبناء والتنسيق منفصلة عن فحوص اللعب.

متصفح بيئة التطوير يحجب التنقل المباشر إلى `file:///` بسياسة `ERR_BLOCKED_BY_ADMINISTRATOR`. يبقى هذا الاختبار مفعّلًا في مجموعة `reliability` ويُشغّل على GitHub؛ لا يُحوّل إلى نجاح صوري أو حالة متجاوزة. اختبار بايتات الملف المنزّل وتشغيلها دون شبكة فحص منفصل يظل قابلاً للتنفيذ محلياً.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع متصفح النظام المثبت: `CHROMIUM_PATH=/usr/bin/chromium npm test`. دون هذا المتغير تستخدم الاختبارات متصفح Playwright المضمّن كما في GitHub. يعمل المشغّل بعمليتين متوازيتين افتراضياً؛ اضبط `LAMMA_TEST_WORKERS` من 1 إلى 4 عند الحاجة.

## الحدود العملية

الفحوص تستخدم Chromium ومحاكاة أحجام الهاتف واللمس. تُستخدم لوحات وكلمات وتوقيتات محددة لإعادة الحالات النادرة، مع ألغاز مولّدة وجلسات كاملة في الحالات الأخرى. لا تعادل هذه التغطية تجربة كل هاتف ومتصفح وتقنية مساعدة أو إثبات غياب كل خطأ ممكن. نتيجة axe تخص القواعد والشاشات المفحوصة.

اللعب الجماعي بالتناوب على جهاز واحد، والحفظ محلي بصيغة التقدم 3. لا يتضمن تنزيل HTML أسماء اللاعبين أو أسرار الجولة أو التقدم؛ نقل البيانات يستعمل JSON منفصلاً. لا تُحفظ الجولات السرية؛ يبقى استكمال اللغز المستقل خاصاً بفك الشفرة وترتيب الأرقام وسودوكو.
