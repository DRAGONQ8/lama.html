# التحقق من لَمّة 9

## نطاق الفحص

يشغّل المشروع **29 مجموعة متصفح**: مجموعات الإصدارات السابقة، و7 مجموعات جديدة للإصدار 9. تشمل الألعاب الـ34، الحفظ والاستيراد والمزامنة، الإيقاف والخصوصية، نتائج الجولات، والعمل دون الشبكة.

- العودة من الإعداد واللعب والنتيجة والمسار والاستراحة إلى موضع الكتالوج، مع البحث والفلاتر والتركيز. الرجوع والتقدّم في المتصفح لا يعيدان نتيجة أو بطاقة سرية قديمة.
- ثلاث قرعات مستقلة للفرد والشخصين والمجموعة؛ تُستنفد الألعاب المناسبة قبل تكرارها. تُراجع أسماء الزوج المختار وعدد اللاعبين عند البدء، دون تغيير قائمة اللاعبين المحفوظة.
- خزنة الأرقام، مهمة الأقفال الثلاثة، التحقيق اليدوي، دفتر المشتبهين، مواجهة الذاكرة، حكاية التمثيل، تحقيق كلمة السر، ورد الفعل الاتجاهي؛ مع صحة التكلفة والنتيجة ومنع الأزرار القديمة.
- القاعدة المعكوسة لإكس أو، استبعاد مواضع الشفرة، الاستماع والاستدعاء المؤجل، تثبيت صفوف الأرقام، تفتيش السودوكو، الحساب الناقص، قواعد الرموز، دفاتر الفروق، مساعدات الحروف، والتصويت الخاص.
- توصيل الثعبان، ورشة الدمج، مسح الآثار، وتوصيل طرود المتاهة. فحوص خصائص مستقلة تشمل 2,000 حركة دمج، و90 حقل مسح، و60 مسار توصيل.
- التحقق من الأخبار، مهام العبارات، مختبر الفرضيات، والاعتراض المتحرك. فحص الأدلة دون استخدام الحل المخفي، رسوم المساعدات التراكمية، موضع الهدف الفعلي، تجميد الحركة في الاستراحة، وتكرار المحتوى بالبذور نفسها.
- تتابع قادة الفرق مع وقت واحد، اتهامات ودفاع قبل التصويت الخاص، والحكاية المتسلسلة دون كشف تاريخ الكاتب قبل العرض.
- ألغاز المرآة ذات الحل الفريد، شبكات مفاتيح قابلة للحل، حيّان للأنابيب، والرسم المتصل كعملية تراجع واحدة؛ إلغاء اللمسة عند الإيقاف أو الانقطاع.
- الفحص العام للواجهة يراجع 809 شاشات على عروض 320 و360 و390 و768 و1440px. للأوضاع الجديدة فحوص إضافية للهاتف والكمبيوتر، وحدود الشاشة والتحكم والخصوصية.

## النتيجة المحلية

نجح `npm run build` و`npm run check` وفحص الفروقات. ملفا `index.html` و`lamma_universe.html` متطابقان ومطابقان للمصدر، بحجم يقارب **1.21MB**. لا يحتاج ملف التسليم موارد أو مكتبات من الشبكة.

اجتازت **28 من 29 مجموعة** في البيئة المحلية. المجموعة الوحيدة التي تعيد خطأ هي `reliability`: اجتازت 19 حالة، وتعذر فحص فتح `file:///` لأن Chromium في هذه البيئة يرفضه بـ `ERR_BLOCKED_BY_ADMINISTRATOR`. هذا قيد موجود في البيئة على الملف الأصلي أيضًا؛ لم يُحذف الفحص أو يُتجاوز. نجحت اختبارات العمل دون الشبكة عبر HTTP، والاختبارات الأخرى للألعاب والحفظ والملاحة.

أُعيد بناء النسخة بعد تنسيق المصدر وتوضيح التعليمات، وأُعيد فحص المجموعات المتأثرة. التقارير والصور المحلية تحفظ في `test-results/` ولا تدخل ملفات المصدر.

## تحقق نسخة التنزيل

تشغّل [GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions) المجموعات الـ29 على النسخة المرفوعة. مسار **Downloadable HTML release** يعيد فحص البناء وكل مجموعات المتصفح، بما فيها فتح ملف HTML دون إنترنت، قبل نشر الملف. راجع تشغيل الإصدار `v9.0.0` لنتيجة النسخة المنشورة.

[ملف الإصدار 9](https://github.com/DRAGONQ8/lama.html/releases/download/v9.0.0/lamma_universe.html) هو الملف المستقل نفسه؛ [صفحة الإصدار](https://github.com/DRAGONQ8/lama.html/releases/tag/v9.0.0) تعرض المرفق وملاحظاته.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

أمر المشروع يختبر الملف المجمّع في المجموعات التي تدعم ذلك؛ مجموعات المنطق والملاحة والمزامنة تجمع المصدر مباشرة. فحص البناء يضمن مطابقة المصدر لملف التسليم.

## الحدود العملية

اللعب الجماعي بالتناوب على جهاز واحد. الحكم على التمثيل والشرح بيد اللاعبين. الفحوص تغطي القواعد والمسارات المذكورة ولا تحصر كل تسلسل ضغط أو كل جهاز ونظام تشغيل. محاكاة تغير مساحة الشاشة لا تعادل اختبار كيبورد Android/iOS على جهاز فعلي. مساعدات اللوحات المنزلقة الأكبر من 3×3 تستخدم مسارًا مضمونًا قد لا يكون الأقصر.

يحفظ التطبيق آخر لغز فردي مستقل غير مكتمل من الشفرة أو ترتيب الأرقام أو السودوكو فقط؛ يستعيد الملاحظات والتثبيت مع بداية سجل تراجع فارغ. الجولات السرية ومهمات الأقفال لا تدخل هذا الحفظ. النقاط والنسخ الاحتياطية تبقى على صيغة الإصدار 3 السابقة.
