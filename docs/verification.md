# التحقق من لَمّة 8

## نطاق التحقق

- 22 مجموعة متصفح: المجموعات الـ15 السابقة، و7 مجموعات جديدة لألعاب الإصدار 8 والحفظ المتزامن.
- تشغيل الألعاب الـ34، إعداداتها وأدلتها ونتائجها، على عروض 320 و360 و390 و768 و1440px. الفحص الموسع راجع 809 شاشات دون عيوب تخطيط مثبتة أو أخطاء JavaScript.
- اختبار جميع الأوضاع الجديدة في مجموعاتها الخاصة: المواجهات والتسلسل العكسي وقواعد الألوان والأنماط، المعرفة والكلمات، الأهداف المخفية، لوحات الأركيد، خطط المنطق، وأسئلة وتصويت المجموعة.
- حلول أنوار مستقلة في المقاسات المدعومة، متاهات بمفاتيح وبوابات متسلسلة، مساعد ألغام من الأدلة الظاهرة حتى مع أعلام خاطئة، ودمج الأرقام دون فقدان مجموع قيم البلاطات.
- الخصوصية في الاستراحة وتمرير الجهاز، رفض الأزرار القديمة، منع تكرار النتيجة، والتحكم باللمس ولوحة المفاتيح.
- التخزين من تبويبين بنفس العنوان: كتابات متزامنة قسرية، استيراد وتصفير، إعادة تحميل دون تكرار، جولات متطابقة في نفس اللحظة، وفشل التخزين ثم إعادة المحاولة.
- الحفظ والاستكمال والاستيراد والأسماء العربية والفارسية والسالبة والنطاقات الكبيرة والعمل دون طلب موارد خارجية.

## نتيجة البناء والاختبارات

نجح `npm run build` و`npm run check` وفحص الفروقات. `index.html` و`lamma_universe.html` متطابقان ومطابقان للمصدر؛ حجم الملف قرابة 989KB، ويحتوي الأنماط والبرامج والمحتوى دون تبعيات شبكية.

اجتازت مجموعات الإصدار 8 الجديدة اختبارات المتصفح: core 11، advanced 12، arcade 12، words 5، party 4، lab 9، storage 9. اجتازت أيضًا المجموعات السابقة، بما فيها 23 فحص expansion و809 شاشات browser-v7، بعد تحديث محدد زر الكلمة ليتوافق مع حماية رقم الدور الجديدة.

فحص reliability المحلي ينجح في 19 حالة، ويتعذر فحص فتح `file:///` لأن Chromium في بيئة العمل يرفضه بـ `ERR_BLOCKED_BY_ADMINISTRATOR`. ظهر القيد على الملف الأصلي قبل التطوير. بقي الفحص مفعّلًا دون تخطي؛ لذلك يعيد `npm test` خطأ في هذه البيئة المحلية. تشغيل كل الألعاب دون الشبكة عبر HTTP اجتاز الفحص.

[GitHub Actions](https://github.com/DRAGONQ8/lama.html/actions) يشغّل المجموعات الـ22 على النسخة المرفوعة، بما فيها فتح ملف HTML دون إنترنت. راجع تشغيل آخر commit لنتيجة الفحص في بيئة GitHub؛ تقرير البناء المحلي لا يحل محل نتيجته.

## إعادة الفحص

```sh
npm ci
npm run build
npm run check
npx playwright install --with-deps chromium
npm test
```

مع Chromium مثبت على النظام:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

الاختبارات الجديدة تقرأ الملف المجمّع عند تشغيلها من أمر المشروع، باستثناء مجموعتي lab وstorage اللتين تجمعان المصدر مباشرة. فحص البناء يضمن مطابقة المصدر لملف التسليم. تُحفظ صور الواجهة وتقارير القياسات في `test-results/`، ولا تدخل ملفات النتائج في المصدر.

## حدود التحقق

اللعب الجماعي على جهاز واحد؛ لا يوجد اتصال بين الأجهزة. الحكم على التمثيل والشرح بيد اللاعبين. الاختبارات تغطي القواعد والمسارات المذكورة، ولا تحصر كل تسلسل ضغط ممكن أو كل نظام تشغيل. محاكاة viewport ليست تجربة فعلية لكل كيبورد Android/iOS. مسار تلميح اللوحات المنزلقة الأكبر من 3×3 مضمون، وقد لا يكون الأقصر.

تزامن الحفظ يستخدم بيانات نقل محلية خارج النسخة الاحتياطية. إعادة تحميل التبويب تعيد استخدام هويته، والتبويبات التي لم تسجّل نقاطًا لا تضيف هوية. تُحفظ هويات التبويبات القديمة لمنع فقد مساهمة تبويب مجمّد؛ التصفير والاستيراد يبدآن سجل مزامنة جديدًا.
