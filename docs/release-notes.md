- ثلاث ألعاب جديدة للمجموعة: **كأس اللمّة** لبطولة فريقين في التمثيل والكلمات الممنوعة والمعلومات، و**الكلمة الدخيلة** للكلمات السرية والتصويت، و**مجلس الإبداع** للردود الطريفة التي تُعرض دون أسماء قبل التصويت.
- ثلاثة ألغاز جديدة: **لوحة المنطق** بألغاز Nonogram ذات حل واحد، و**طفّي الأنوار** بلوحات قابلة للحل وتلميحات لأقصر حل، و**مهندس الأنابيب** لبناء شبكة متصلة دون فتحات.
- صفحة رئيسية وصالة للمجموعة، وفلتر للألعاب الجديدة، وترتيب المكتبة حسب المقترح أو الاسم أو آخر لعب أو عدد الجولات.
- ثلاثة مسارات فردية، كل منها ثلاث محطات بنتيجة حتى 300 نقطة: **صفاء الذهن** و**روح المستكشف** و**تحدّي المحترف**. تحفظ المحطات المكتملة وأفضل نتيجة؛ المحطة غير المكتملة تبدأ من جديد عند استكمال المسار.
- استكمال آخر لغز فردي مستقل غير مكتمل من **فك الشفرة** أو **رتّب الأرقام** أو **سودوكو**، مع اللوحة والمحاولات والمساعدات والملاحظات ووقت اللعب. سجل التراجع يبدأ فارغًا بعد الاستعادة؛ لا يشمل هذا الحفظ الألعاب الجماعية أو الجولات اليومية أو جولات البطولة.
- إصلاح تطبيع أسماء اللاعبين واستيراد النسخ الاحتياطية والقيم غير الصالحة للنقاط، ومنع تسجيل النتيجة مرتين، وتسجيل مشاركة طرفي ألعاب اللوحات، والتعامل مع التعادل بالتساوي.
- تحسين إيقاف الوقت والإدخال أثناء الاستراحة والنوافذ، وتنظيف المؤقتات، وحماية انتقال الأدوار السرية، وإصلاحات للثعبان والمتاهة وألعاب الكلمات والأهداف.
- توسيع المصدر بوحدات للمجموعة والمنطق وتجربة الاختيار والمسارات، وإضافة اختبارات للعب والحفظ والألغاز الجديدة. يتحقق مسار الإصدار من البناء واختبارات المتصفح قبل النشر.
